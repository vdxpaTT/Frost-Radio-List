❄️ Frost Radio List – Modern NUI Redesign

Over the past two days I've been working on a complete redesign of the X-Radiolist UI. I wanted something cleaner, more modern, and better suited to today's FiveM servers, so I rebuilt the interface with an entirely new look while keeping the original functionality.

✨ Features
• Modern glassmorphism-inspired interface
• Cleaner player & radio channel list
• Improved spacing and readability
• Smoother overall appearance
• Easy to integrate into existing servers
